# Benchmarks

This folder contains curated, English-language benchmark notes. Exploratory raw JSON, JSONL logs, model checkpoints, and local training outputs stay in the ignored `reports/` and `models/` directories.

- [Methodology](methodology.md): evaluation contract and recommended reporting.
- [Results](results.md): selected measurements, configurations, and limitations.

A benchmark result is useful only when its agent configuration, checkpoint identity, seed range, and evaluation procedure are clear. Historical reports with missing checkpoint provenance are retained as measurements, not advertised as fully reproducible comparisons.
